# Step 1: AI Platform Accounts + Apps

**What:** Sign up for AI platforms and install every app they offer — desktop, mobile, and web.
**Time:** ~15 minutes
**Requires:** Nothing — this is where you start.

Each AI platform gives you multiple ways to interact with it — a web interface, a desktop app, and a mobile app. Install all of them for whichever platforms you subscribe to. Different situations call for different tools: you'll use the web or desktop app for focused work sessions, the mobile app for quick questions on the go, and the developer tools (set up in [Part 2](index.md#part-2-builder-tools)) for hands-on building.

You only need **one** platform to get started. Claude is the primary platform used throughout this cookbook, but all four platforms are covered.

---

## Claude (Anthropic)

Requires a **Claude Pro, Max, or Team** subscription.

1. Go to [claude.ai](https://claude.ai) and sign up (or sign in)
2. Upgrade to **Claude Pro** ($20/month) or **Claude Max** for extended usage
3. Install all available apps:
    - **Desktop:** [claude.ai/download](https://claude.ai/download) — macOS and Windows
    - **Mobile:** [App Store](https://apps.apple.com/app/claude-by-anthropic/id6473753684) or [Google Play](https://play.google.com/store/apps/details?id=com.anthropic.claude)
4. Sign in to each app with your account

**Official docs:** [Claude Support — Getting started](https://support.claude.com)

---

## ChatGPT (OpenAI)

Requires a **ChatGPT Plus or Team** subscription.

1. Go to [chatgpt.com](https://chatgpt.com) and sign up (or sign in)
2. Upgrade to **ChatGPT Plus** ($20/month) or **ChatGPT Team** for the full feature set
3. Install all available apps:
    - **Desktop:** [openai.com/chatgpt/desktop](https://openai.com/chatgpt/desktop/) — macOS and Windows
    - **Mobile:** [App Store](https://apps.apple.com/app/chatgpt/id6448311069) or [Google Play](https://play.google.com/store/apps/details?id=com.openai.chatgpt)
4. Sign in to each app with your account

**Official docs:** [OpenAI Help Center — Getting started](https://help.openai.com/en/collections/3742473-chatgpt)

## Gemini (Google)

=== "Personal account"

    Requires a **Gemini Advanced** (Google One AI Premium) subscription.

    1. Go to [gemini.google/subscriptions](https://gemini.google/subscriptions/) and sign in with your Google account
    2. Upgrade to **Gemini Advanced** ($20/month via Google One AI Premium) for the full feature set
    3. Install all available apps:
        - **Desktop:** [Google Gemini desktop app](https://blog.google/products/gemini/google-gemini-desktop-app/)
        - **Mobile:** [App Store](https://apps.apple.com/app/google-gemini/id6477141240) or [Google Play](https://play.google.com/store/apps/details?id=com.google.android.apps.bard)
    4. Sign in to each app with your Google account

    **Official docs:** [Gemini Help Center](https://support.google.com/gemini)

=== "Workspace account"

    Your Workspace admin enables Gemini — check with IT if you don't have access.

    1. Go to [Google Workspace AI](https://workspace.google.com/solutions/ai/) to explore Gemini for your organization
    2. Once enabled, access Gemini at [gemini.google.com](https://gemini.google.com) with your work account
    3. Install available apps:
        - **Mobile:** [App Store](https://apps.apple.com/app/google-gemini/id6477141240) or [Google Play](https://play.google.com/store/apps/details?id=com.google.android.apps.bard)

    **Official docs:** [Google Workspace AI solutions](https://workspace.google.com/solutions/ai/)

=== "Enterprise"

    Your Google Cloud admin provisions Gemini Enterprise — check with IT if you don't have access.

    1. Go to [Gemini for Google Cloud](https://cloud.google.com/gemini-enterprise) to explore enterprise options
    2. Once enabled, access Gemini through Google Cloud Console and integrated Google services

    **Official docs:** [Gemini Enterprise](https://cloud.google.com/gemini-enterprise)

## Microsoft 365 Copilot

Requires a **Microsoft 365** subscription with **Copilot** enabled.

1. Go to [copilot.microsoft.com](https://copilot.microsoft.com) and sign in with your Microsoft account
2. Ensure your **Microsoft 365** subscription has **Copilot** enabled
3. Install all available apps:
    - **Desktop:** Update Microsoft 365 apps (Word, Excel, Teams) to the latest version to enable Copilot
    - **Mobile:** [App Store](https://apps.apple.com/app/microsoft-copilot/id6738321700) or [Google Play](https://play.google.com/store/apps/details?id=com.microsoft.copilot)
4. Sign in to each app with your Microsoft account

**Official docs:** [Microsoft Copilot Help](https://support.microsoft.com/en-us/copilot)
